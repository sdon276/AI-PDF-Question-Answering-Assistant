# AI PDF Question-Answering Assistant

A beginner-friendly AI project that answers questions using information from an uploaded PDF.

## Project Description
This project uses Python to extract text from a PDF and Google Gemini API to answer questions based on the PDF content.

## Technologies Used
- Python
- Google Colab
- PyPDF
- Google Gemini API

## How It Works
1. Upload a PDF file.
2. Extract and clean the PDF text.
3. Enter a question.
4. Send the PDF content and question to Gemini.
5. Display an AI-generated answer based on the document.

## Features
- Answers questions using PDF content.
- Uses Gemini to generate answers.
- Instructs the AI not to invent information missing from the PDF.

## What I Learned
- Reading PDF files using Python.
- Extracting and cleaning text.
- Working with API keys securely.
- Connecting Python with Google Gemini API.
- Building a basic document-grounded AI assistant.

## Note
This is a beginner-level document question-answering project. It uses the PDF text as context and does not yet implement semantic search or a complete retrieval-based RAG pipeline.
